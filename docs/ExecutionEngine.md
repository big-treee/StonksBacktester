# Execution Engine

The Execution Engine models real world broker interactions order execution logic transaction costs and slippage.

## Features

1. **Broker Models**: Zerodha Upstox Groww Angel One and Zero Charge modes.
2. **Indian Tax Calculation**: Computes STT GST Exchange turnover fees Stamp duty and SEBI turnover fees accurately in INR (₹).
3. **Realistic Fills**: Fills orders using current bar market price without look ahead bias.
