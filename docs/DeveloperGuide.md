# Developer Guide

Welcome to the StonksBacktester repository! This guide provides standard operating procedures for contributing to the core engine API and frontend.

## Local Environment Setup

1. **Clone and Install**
   ```bash
   git clone https://github.com/your-username/stonks-backtester.git
   cd stonks-backtester
   pip install -e .
   ```

2. **Run Tests**
   ```bash
   pytest
   ```
