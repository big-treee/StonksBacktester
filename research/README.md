# Research Engine Directory

Welcome to the StonksBacktester Research Engine.

## Overview
This directory serves as the centralized repository for all backtesting results reports charts and metrics generated by the core backtester. To ensure clean datasets and avoid folder clutter all experimental runs should be executed using the single entry point script at the root:

```bash
nse-quant run
```

## Folder Structure

### `results/`
Contains automated run artifacts generated after running a backtest simulation. Each subfolder is timestamped to ensure reproducibility.
* `config.yaml`: Frozen config used during the backtest run.
* `summary.json`: High level performance metrics payload.
* `trades.csv`: Complete trade log for post backtest analysis.
* `metrics.json`: Granular portfolio performance metrics.
* `tearsheet.html`: Standalone HTML tearsheet report.

### `reports/`
Contains human readable markdown reports and analysis.
* `stonksbacktester_readiness.md`
* `duplicate_strategy_analysis.md`
* `performance_report.md`
